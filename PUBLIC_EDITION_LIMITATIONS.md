# Public Edition limitations

The stable Community Edition is a cleaned publication copy of **formal NTU-v002**. It is deliberately not the latest private working checkpoint. Historical releases are approximate, PARTIAL development snapshots; technical acceptance never meant the whole campus was accurate or complete.

- Coverage: Nanyang Technological University, Singapore — Yunnan Garden main campus including NIE. 345 stable OSM building IDs originate in 346 polygon parts; mesh counts vary because components are split/merged. No claim that OSM covers every campus structure.
- Coordinates: meters, local offsets from EPSG:3414 at longitude 103.683 / latitude 1.3483. Flat elevation basis, no terrain DEM. Heights, facades, roof details, roads, vegetation and landscaping contain estimates.
- The 1 cm threshold in validation checks only Blender 5.2.1 LTS ↔ GLB numerical consistency, not real-world accuracy.
- Formal v002 retains coarse landmark proxies and generic ordinary-building treatment. It is not the later recognition goal's completion.
- Historical public copies restore Block71 (518953947), and in the night snapshot RSB (49968086), to formal generic geometry. Their map/street-view-dependent appearance is REMOVED_FROM_PUBLIC_EDITION pending redistribution review. Thus these copies intentionally differ from the private historical files.
- All reference photos, guide PDFs, source map captures, private notes, logs, paths, issue ledgers, failures and account data are REMOVED_FROM_PUBLIC_EDITION. Private evidence is retained privately, not erased.
- No hidden attribution geometry, tracking code or executable Text blocks. Source credit is ordinary scene/GLB metadata and a readable Blender Text block.
- No model of interiors, construction-grade detail, validated accessible routing, legal boundaries, safety navigation or precision digital twin is promised.

This is an independent community reconstruction project. It is not affiliated with, endorsed by, or officially produced by the university.
