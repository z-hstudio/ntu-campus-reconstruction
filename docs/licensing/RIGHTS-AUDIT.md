# Rights / redistribution audit

| Class | Assets / rights | Decision |
|---|---|---|
| A ORIGINAL_ZHSTUDIO | Author-directed, AI-assisted procedural mesh expressions, generic materials, composition, original documentation | Community License only to the extent original rights subsist; no exclusive claim to underlying real architecture or data |
| B REDISTRIBUTABLE_THIRD_PARTY | No embedded third-party meshes, textures, fonts or scanned media found | None shipped |
| C PUBLIC_DATA_WITH_ATTRIBUTION | OSM footprints, boundary and road/land-use data; adapted spatial database | ODbL 1.0, © OpenStreetMap contributors; corresponding database ZIP in each Release |
| D REFERENCE_ONLY | NTU/architect/supplier photos, web pages and guide PDFs | Links and limited factual descriptions only; no source media redistributed |
| E RESTRICTED_OR_UNCLEAR | Google map/Street View-derived later changes; third-party imagery redistribution; logos/artwork and private files | Excluded; Block71 and RSB reverted in public copies; R29–R32 excluded |

No original architectural plans, photogrammetry, LiDAR, DEM or imported proprietary model was found in the selected model dependencies. All selected inputs are procedural scenes. There is no universal permission inferred from accessibility or packing.

Architecture and trademarks are not claimed by this project. Singapore's [Copyright Act 2021](https://sso.agc.gov.sg/Act/CA2021) contains specific exceptions for depicting and reconstructing buildings; this audit does not assert a blanket worldwide right to copy architectural designs or artwork in 3D. The release is an approximate procedural interpretation, not copied CAD or source image reproduction. Intended high-fidelity/commercial uses may need independent rights clearance. This is a practical asset inventory and licence allocation, not a legal opinion.

[ODbL](https://opendatacommons.org/licenses/odbl/1-0/) and the [OSMF Produced Work guideline](https://osmfoundation.org/wiki/Licence/Community_Guidelines/Produced_Work_-_Guideline) inform the separation of database and original-content rights. Non-commercial conditions are not imposed on OSM's own grant.
